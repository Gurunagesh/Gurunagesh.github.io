PROJECT 01

DiabetesIQ — Smart Diabetes Detection System

An academic diabetes risk-screening application designed to explore clinical, lifestyle, demographic and comorbidity factors through machine learning.

What I built

  • Processed 5,292 patient records and performed data cleaning and feature engineering.
  • Compared Logistic Regression, Decision Tree, Random Forest and XGBoost models.
  • Built a Streamlit interface with risk probability, Low/Medium/High risk bands, SHAP explanations and what-if analysis.
  • Implemented an ensemble approach using Logistic Regression and XGBoost.
Academic screening prototype, not a medical device or diagnostic tool. Labels were reconstructed using a clinical risk-scoring approach; independent clinical validation is still required.
Python Scikit-learn XGBoost SHAP Streamlit

PROJECT 02

Agentic AI Meeting Assistant

An LLM-powered meeting assistant that transforms meeting transcripts into structured summaries, decisions, risks and actionable tasks with human approval.

What I built

  • Supports TXT, VTT and SRT transcript inputs.
  • Integrated Gemini with Grok fallback and mock mode.
  • Implemented SHA-256 duplicate detection, confidence-based approval workflows and audit logging.
  • Deployed FastAPI backend on Render and Streamlit frontend on Streamlit Community Cloud.
  • Migrated MySQL persistence to TiDB Cloud Serverless, using SSL/TLS database connections and CA validation.
  • Added environment-based secrets management, structured database error handling and frontend retry logic.
Python FastAPI Streamlit Gemini TiDB Cloud Docker

PROJECT 03

CFPB Consumer Complaint Intelligence Platform

A consumer complaint analytics platform focused on understanding complaint patterns, data quality, operational trends and potential machine learning use cases.

What I built

  • Worked with 81,946 consumer complaint records across 16 attributes using MySQL and Python.
  • Performed data profiling, missing-value analysis, duplicate checks and exploratory data analysis.
  • Examined complaint products, geographic patterns, response timelines and narrative characteristics.
  • Investigated class imbalance, target leakage risks and potential ML prediction targets.
